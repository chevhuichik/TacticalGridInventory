# Tactical Grid Inventory

Grid inventory for Project Zomboid Build 42, inspired by Escape from Tarkov: items take space,
rigs and backpacks have pockets, loot has to be searched, gear is worn on slots around your character.

- Steam Workshop: https://steamcommunity.com/sharedfiles/filedetails/?id=3810674933
- Version: 1.6.23
- Requires: ZombieBuddy
- Changelog: `common/ChangeLog.bbcode`

Install it from the Workshop page. This repository holds the released files only.
